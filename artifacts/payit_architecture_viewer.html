Feature 1: Non-Custodial Dual-Wallet & PIN Security

Independent wallet generation, scrypt key derivation, AES-256-GCM encryption, in-memory transient decryption, and rate-limited PIN security.

src/wallet.js src/db.js src/multichain.js 
sequenceDiagram
    autonumber
    actor User as Telegram User
    participant Bot as bot.js
    participant DB as src/db.js (pin_security)
    participant Wallet as src/wallet.js
    participant Multi as src/multichain.js

    Note over User,Wallet: 1. Wallet Generation Flow (/start)
    User->>Bot: /start
    Bot->>Wallet: ethers.Wallet.createRandom()
    Wallet->>Wallet: Generate Random Salt
    User->>Bot: Enters 4-digit PIN (e.g. 1234)
    Bot->>Wallet: scrypt(PIN, salt) → 256-bit AES Key
    Wallet->>Wallet: AES-256-GCM encrypt(PrivateKey)
    Wallet->>Multi: deriveSolanaFromEvmKey(PrivateKey)
    Multi-->>Wallet: Deterministic Solana Ed25519 Address
    Wallet->>DB: Save { personal_address, solana_address, encrypted_blob, salt }
    Bot-->>User: Wallet Initialized (Keys self-destruct after 60s)

    Note over User,Wallet: 2. Transient Key Decryption Flow
    User->>Bot: Request On-Chain Transfer / Withdrawal
    Bot->>DB: Verify lockout threshold (attempts < 5)
    User->>Bot: Enters 4-digit PIN
    Bot->>Wallet: scrypt(PIN, salt)
    Wallet->>Wallet: Decrypt blob with AES-256-GCM
    alt PIN Incorrect
        DB->>DB: Increment failed_attempts (Lockout up to 1 hr if >= 5)
        Bot-->>User: ❌ Incorrect PIN
    else PIN Valid
        DB->>DB: Reset failed_attempts to 0
        Wallet->>Wallet: Sign transaction in RAM
        Wallet->>Wallet: Wipe plaintext private key from RAM immediately
        Wallet-->>Bot: Signed Transaction Payload
    end

Feature 8: DeFi Savings, Morpho Yield & Auto-Earn Daemon

Scans for funds sitting idle for 2+ hours, auto-deposits into Morpho ERC-4626 vaults, and auto-liquidates upon user spending with 10% dev fee routing.

    participant Vault as ERC-4626 Vault Contract on Arc
    actor User as Telegram User

    Note over Daemon,Vault: Background Auto-Allocation (2-Hour Idle Funds)
    Daemon->>DB: getIdleUsersForAutoEarn(idleHours >= 2)
    DB-->>Daemon: List of users with idle USDC > $5.00
    Daemon->>Kit: getYieldPools() → Best APY Vault (e.g. 8.4% APY)
    loop For Each Idle User
        Daemon->>Vault: deposit(balance - $0.50 gasBuffer)
        Vault-->>Daemon: Mint ERC-4626 Shares
        Daemon->>DB: openYieldPosition(isAutoEarn = true, principal)
    end

    Note over User,Vault: Instant Auto-Liquidation on Spend
    User->>Bot: Initiates Payment / Transfer ($50)
    Bot->>DB: Check Liquid Balance
    alt Insufficient Liquid Balance & Active Yield Position Exists
        Bot->>Vault: redeem(shares) / withdraw(assets)
        Vault-->>Bot: Principal + Accrued Interest
        Bot->>Bot: Calculate 10% Dev Fee on Accrued Profit
        Bot->>DB: Route 10% Fee to PayIT Treasury, 90% Profit to User
        Bot->>DB: closeYieldPosition()
        Bot-->>User: ⚡ Liquidated auto-earn vault ($50.24 returned)
    end
